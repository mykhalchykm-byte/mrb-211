# 🎯 Квізоут — вікторина в стилі Kahoot

Викладач показує **питання на головному екрані** (проєктор / телевізор), а учні на телефонах бачать
**лише варіанти відповідей** (кольори й фігури, за бажанням — з текстом відповідей) і обирають свою.

## Запуск

Потрібен [Node.js](https://nodejs.org) 18 або новіший.

```bash
npm install
npm start
```

У терміналі з'явиться **одне посилання для всіх** (наприклад `http://192.168.1.20:3000`).
Телефони мають бути в тій самій Wi-Fi мережі, що й комп'ютер вчителя.
На сторінці за цим посиланням кожен обирає роль: **«Я учень»** або **«Я вчитель»**.

- **Вчитель** вводить код доступу **`MRB211`** (код перевіряється на сервері).
  Змінити код: `TEACHER_CODE=НОВИЙ_КОД npm start`.
- **Учні** входять **без коду** — достатньо ввести ім'я.

Порт можна змінити: `PORT=8080 npm start`.

## Як проходить гра

1. Вчитель входить за кодом, створює вікторину (питання, 2–4 варіанти, правильна відповідь,
   час на відповідь) і натискає **▶ Запустити**.
2. Учні відкривають те саме посилання, обирають «Я учень» і вводять ім'я.
   PIN гри з 4 цифр (його видно на екрані вчителя) потрібен лише якщо одночасно відкрито кілька ігор.
3. Вчитель натискає **Почати гру**. **На головному екрані** — питання та варіанти відповідей,
   **на телефонах учнів** — лише символи: ▲ трикутник, ◆ ромб, ● коло, ■ квадрат.
4. Після кожного питання — розподіл відповідей і топ-5. Наприкінці — підсумки, їх можна завантажити в CSV.

Бали: до 1000 за правильну відповідь (чим швидше, тим більше) + бонус за серію правильних відповідей.

## Можливості

- Вікторини зберігаються в браузері викладача; є **імпорт / експорт** у файл `.json`.
- Учень може оновити сторінку й повернутися в гру (так само й викладач, протягом 2 хвилин).
- Викладач може видалити учня з лобі, достроково завершити питання.
- Захист від підбору коду вчителя: після 5 помилок — пауза на хвилину.

## Щоб учні грали не лише в одній мережі (через інтернет)

Розмістіть проєкт на будь-якому хостингу з підтримкою Node.js і WebSocket
(Render, Railway, Fly.io, VPS) з командою запуску `npm start` — порт береться зі змінної `PORT`.

### Render за кілька кроків (є файл `render.yaml`)

1. Завантажте папку проєкту в новий репозиторій на GitHub.
2. На render.com: **New → Blueprint**, оберіть цей репозиторій.
3. Render запитає значення `TEACHER_CODE` — введіть свій код вчителя (якщо залишити порожнім, діє `MRB211`).
4. Після розгортання отримаєте посилання виду `https://kvizout.onrender.com` — це і є одне посилання для всіх.

Безкоштовний тариф «засинає» без відвідувачів — відкрийте посилання за кілька хвилин до уроку.
Для швидкого показу на уроці можна скористатися тунелем (Cloudflare Tunnel, ngrok).

## Структура

```
server.js            сервер: кімнати, PIN, підрахунок балів (WebSocket)
public/index.html    початкова сторінка: вибір «учень / вчитель»
public/teacher.html  сторінка вчителя (код, редактор, ведення гри)
public/student.html  сторінка учня (лише символи відповідей)
public/style.css     спільні стилі
test.js              автотест повної гри (npm test)
```

## Збереження вікторин вчителя

Вікторини зберігаються на сервері й доступні з будь-якого пристрою після входу з кодом вчителя.
Безкоштовний Render **стирає файли** при кожному перезапуску (сервіс «засинає» після ~15 хв без відвідувачів),
тому для постійного збереження потрібна база даних:

1. Створіть безкоштовну базу PostgreSQL (наприклад, на supabase.com або neon.tech) і скопіюйте рядок підключення (`postgresql://…`).
   У Supabase: Project Settings → Database → Connection string → Session pooler.
2. У Render: сервіс → Environment → додайте змінну `DATABASE_URL` з цим рядком → Save (сервіс перезапуститься).
3. Таблиця створюється автоматично. Якщо на сторінці вчителя біля «Мої вікторини» стоїть «☁ Збережено на сервері» — все гаразд;
   «⚠ Тимчасове сховище» означає, що `DATABASE_URL` не задано.

Альтернатива (платна): Persistent Disk на Render, змонтований у `/data`, і змінна `DATA_DIR=/data`.
Підказка ✅ для імені: змінна `HINT_NAME` (за замовчуванням «Михальчук», порожнє значення — вимкнути).

## Telegram-бот (сповіщення і керування)

Бот повідомляє про нові/змінені/видалені вікторини, початок і результати кожної гри (рейтинг, середній бал, найскладніші питання),
перезапуски сервера та збої бази даних, а також дає команди керування. Налаштування:

1. У Telegram знайдіть **@BotFather** → `/newbot` → придумайте назву й логін (має закінчуватись на `bot`) → скопіюйте **токен**.
2. У Render → Environment додайте `TELEGRAM_BOT_TOKEN` = токен. Збережіть (сервіс перезапуститься).
   Для кнопок посилань додайте також `PUBLIC_URL` = адреса сайту, наприклад `https://mrb-211-1.onrender.com`.
3. Відкрийте свого бота в Telegram, натисніть Start і надішліть `/login КОД_ВЧИТЕЛЯ`. Чат підключено — можна підключити кілька чатів.

Команди: `/status`, `/quizzes`, `/delete`, `/games` (можна завершити гру), `/results`, `/csv` (файл для Excel), `/notify` (що сповіщати), `/link`, `/logout`.
Необов'язково: `KEEP_AWAKE=1` — сервер сам відкриває свою сторінку раз на 10 хв, щоб безкоштовний Render не «засинав»;
`TZ_DISPLAY=Europe/Kyiv` — часовий пояс у повідомленнях; `TELEGRAM_CHAT_ID=123,456` — заздалегідь дозволені чати.

## Багато учнів одночасно (100+)

Сервер перевірено тестом на 300 одночасних учнів (вхід, відповіді, рейтинг): усі заходять за долі секунди без помилок.
Що для цього зроблено: сторінки віддаються з пам'яті стиснутими; рейтинг рахується один раз за питання; вчитель отримує
злиті оновлення, а не по одному на кожного учня; підключення, що обірвалось, не валить сервер; подвійний клац «Увійти»
не створює двійників; телефон сам повторює вхід із наростаючою паузою й підключається знову після повернення в браузер.
Учнів у грі за замовчуванням до 400 (змінна `MAX_PLAYERS`).

Поради для великого класу:
- Безкоштовний Render «засинає» без відвідувачів, і перший вхід після цього триває до хвилини. Відкрийте сайт за 1–2 хв до початку
  або задайте `KEEP_AWAKE=1` та `PUBLIC_URL`, щоб сервер не засинав.
- Безкоштовний тариф має мало процесорного часу. Якщо гра «підвисає» на 300+ учнях, переходьте на платний тариф Starter.
- Зважайте, що 4-цифровий PIN можна підібрати: учні можуть спробувати зайти в чужу гру. Сервер блокує підбір після 60 помилок
  за хвилину з однієї адреси.

## Як проходить питання

1. **Спочатку лише питання з відліком.** На головному екрані видно текст питання й таймер (це поле «Час» біля питання, 5–120 с).
   Варіантів ще немає. На телефонах учнів — «Читайте питання» з таким самим відліком, відповідати поки не можна.
2. **Потім варіанти без таймера.** Коли відлік закінчився (або вчитель натиснув «Показати варіанти зараз»), з'являються варіанти
   на екрані вчителя й кнопки на телефонах. Питання завершується, коли відповіли всі учні, або коли вчитель натисне «Завершити питання».
3. «Бали за швидкість» (галочка в лобі, за замовчуванням вимкнена): максимум — за відповідь одразу після появи варіантів, до 50% — через 30 с і довше.
